# Завдання 4 — Explorer транзакцій (useMemo / performance)

**Рівень:** middle · **Концепти:** `useMemo`, derived data, `React.memo`, performance

## Що зробити

Реалізуй `applyFilters` і `summarize` у `filter-transactions.ts`; переконайся, що вони викликаються через `useMemo` з правильними залежностями. Кнопка “Re-render” не має тригерити перерахунок фільтра.

## Філософія

> Похідні дані не зберігай у стані й не рахуй наосліп щорендер. `useMemo` кешує результат, поки залежності ті самі. Але не мемоїзуй усе підряд — лише дороге.
